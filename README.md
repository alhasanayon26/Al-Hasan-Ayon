## Web & Game Projects

### ⌨️ KeySprint - Cafe

**Live: ** [alhasanayon26.github.io/KeySprint--Cafe](https://alhasanayon26.github.io/KeySprint--Cafe/)

**About:** KeySprint is a typing practice web app built to help people get faster and more accurate, with the tagline *"A little practice. A lot more speed."* It runs fully in the browser, works on desktop and mobile, and saves your progress on your own device.

**Features**

- **Typing modes:** Words, Stories, Hard, Punctuation, Code, Quotes, Custom text, Lessons, Data Entry, Game, and VS.
- **Timed tests:** Just Type, 15s, 30s, 1 min, 2 min, or a custom length.
- **Live results:** WPM, raw WPM, accuracy, correct characters, mistakes, a speed-over-time chart, and the keys you should practice.
- **Progress tracking:** history, best WPM per time length, badges, and streaks.
- **Bangla support:** switch the interface and typing practice to বাংলা.
- **KS Code:** a built-in code area with a Run button and AI chat.
- **Your data stays yours:** backup and restore, plus a clear reset option.
- **Share result** and **Copy text** after each test.

**Tech:** HTML, CSS, JavaScript, hosted on GitHub Pages.

### 🌆 Neon City

**Live: ** `Will update soon...`

**About:** Neon City is an open-world 3D sandbox game that runs in the browser. Explore a living city, take on jobs, earn neon (the in-game money), and see how long you can stay out of jail. It plays on a computer (keyboard and mouse) and on a phone or tablet (touch controls).

**Features**

- **Open-world city** with day and night, seasons, traffic, crowds, a metro, lifts, shops, hospitals, and an ATM.
- **1,000 jobs in ten kinds:** delivery, courier, taxi, street race, car theft, getaway, speed trap, bike messenger, collect, and bounty. Bus routes and coins around the city also earn neon.
- **Vehicles:** cars, vans, trucks, bikes, and a city bus, each with its own fuel tank, petrol pumps, mechanics, and garages.
- **On foot:** walk, run, jump, climb onto cars and ledges, sit on benches, and make pedestrians your friends.
- **Weapons and police:** nine weapons and a police system with up to five wanted stars, helicopters, barricades, and jail.
- **Health and shops:** hospitals, ambulances, medicine, a vehicle showroom you can buy, and food stalls.
- **Save system:** multiple save slots, autosave, and Continue / Load game.
- **Settings:** graphics quality, shadows, draw distance, frame rate, dynamic resolution, key bindings, an FPS panel (F3), and screenshot and screen-recording tools.
- **Installable and offline:** works as an app on your device and keeps working without internet after the first visit.

**Tech:** JavaScript, HTML5 Canvas, Three.js (WebGL), service worker for offline play.

## Run locally

This is a static site, so no build step or dependencies are needed.

1. Download or clone the repository.
2. Open `index.html` in any modern browser.

## Deploy on GitHub Pages

1. Make sure the main file is named `index.html` and sits in the repository root.
2. Push the files to a GitHub repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait a minute, then open the link GitHub shows.
